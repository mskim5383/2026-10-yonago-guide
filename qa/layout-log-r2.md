## 검증

```
node build/build.mjs            # 64쪽, 장 시작 맞춤 메모 1(48쪽), 끝 메모 0, 접는 순서 PASS, 경고 1(QR v8)
node build/render-pages.mjs     # qa/pages 64장, qa/booklet 32장
node build/web-shots.mjs        # 390·1280 가로 스크롤 없음
node build/check-qr.mjs         # QR 판독 PASS: 기대 39 · 읽힘 39 · 15.5~18.8mm
node build/test-imposition.mjs  # 합성 4·8·12·16·64·72쪽 + 실물 64쪽 PASS
node build/check-web.mjs        # FAIL: webUrl·PDF 2종 404 (배포 전)
```

- 장 시작: 여는 글 4, 사흘 한눈에 6, Day 1 9, Day 2 15, Day 3 21, 읽을거리 27, 먹고 마실 곳 45, 실용 49(앞 48쪽 메모), 줄 너머로 56, 닫는 글 59, 크레디트 60, 진짜 일기 61, 뒤표지 64. 차례 쪽번호는 빌드가 PDF 제목과 대조했고 경고는 0건이다.
- 64쪽 전부를 펼침면으로 봤다(`tmp/designer/r2/sheets/`). 넘침·잘림 없음, 제목만 쪽 끝에 남는 곳 없음, 장소 카드와 상자가 갈린 곳 없음.
- 고친 지도 라벨 5개는 Chrome에서 viewBox 단위로 쟀다(`tmp/designer/r2/svgends.mjs`). 인쇄 감리의 `svgclip` 검사(복사본 `tmp/designer/r2/svgclip.mjs`)로 viewBox·범례 상자 넘침 0건이다.

## 남은 것

- **웹판 URL 404(인쇄 전 필수)**: 공개 배포 뒤 `node build/check-web.mjs` PASS와 실물 QR 촬영을 확인해야 한다. 저장소 이름이 바뀌면 `book.json` webUrl만 바꿔 다시 빌드하면 된다.
- まるはち屋 지도 QR v8(빌드 경고 1건). 판독과 정렬은 해결됐다. 54의 `data-maps`를 「まるはち屋 米子空港」처럼 줄이면 경고도 없어진다(54 담당 판단).
- 40쪽 한 줄 자간 벌어짐(위 표). 읽는 글 줄바꿈 규칙을 바꿀 때 같이 볼 일이다.
- 장 끝 빈자리: 5쪽 약 1/3, 8쪽 약 1/4, 22쪽·31쪽·32쪽·53쪽 약 1/5, 20쪽·47쪽·57쪽 약 1/6. 모두 장이나 원고 끝, 또는 가르지 않는 상자 때문이다.
- r1에서 넘긴 것 그대로: 장 첫 쪽 러닝헤드 생략(Chrome 미지원), 폰트 woff2 서브셋(fontTools 없음), 실제 종이 인쇄와 휴대폰 스캔은 하지 못했다.
